# 유지보수 가이드

## 콘텐츠 관리 원칙

도구 정보는 `data/tools.js`에서만 수정합니다. HTML에는 개별 도구 카드를 직접 쓰지 않습니다.

필수 필드는 다음과 같습니다.

| 필드 | 용도 |
| --- | --- |
| `id` | DOM 렌더링과 추적에 쓰는 고유 값 |
| `name` | 카드 제목 |
| `description` | 카드 설명 |
| `categories` | 필터에 연결되는 분류 ID 목록 |
| `tags` | 카드 하단의 짧은 키워드 |
| `tone` | 카드 포인트 색상 |
| `marker` | 카드 왼쪽 상단의 짧은 식별자 |
| `status` | 카드 오른쪽 상단의 도구 유형 |
| `primaryUrl` | `열기` 버튼 링크 |
| `sourceUrl` | GitHub 저장소 링크 |

`resourceUrl`과 `resourceLabel`은 워크북처럼 보조 링크가 있을 때만 사용합니다.

## 분류

현재 분류는 다음 기준으로 사용합니다.

- `microbit`: micro:bit와 직접 연결되는 도구
- `sensor`: 센서 데이터 측정 또는 시각화
- `sound`: 사운드 생성 또는 주파수 분석
- `physics`: 물리 실험 또는 물리 개념 관련 도구
- `workbook`: 인쇄용 또는 학습용 워크북 포함

분류 버튼의 표시 순서는 `window.EDULINK_CATEGORIES` 배열 순서를 따릅니다.

## 디자인 수정

색상과 공통 치수는 `assets/styles.css`의 `:root` 변수에서 관리합니다.

- 카드 모서리는 `--radius`로 통일합니다.
- 새 카드 색상은 `.tool-card[data-tone="..."]` 블록을 추가합니다.
- 모바일 레이아웃은 `960px`, `640px` 두 중단점에서 조정합니다.

## 검수 체크리스트

수정 후 다음 항목을 확인합니다.

- `index.html`을 브라우저에서 열었을 때 콘솔 오류가 없는지 확인합니다.
- 검색어 입력 시 카드가 즉시 필터링되는지 확인합니다.
- 각 분류 버튼이 알맞은 도구만 표시하는지 확인합니다.
- 모든 외부 링크가 새 탭에서 열리는지 확인합니다.
- 모바일 폭에서 카드와 버튼 텍스트가 겹치지 않는지 확인합니다.
